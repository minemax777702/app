## 27.11.2026 — статистика походов вместо количества покупок

Поход = уникальный закрытый список (UID), активный список не считается. Сводка и график активности используют дату закрытия; фильтр покупателя сохраняется. В разрезе магазинов/товаров считаются уникальные закрытые списки с соответствующими покупками, один список может присутствовать в нескольких разрезах. Средний чек считается по известным расходам закрытых списков. В архиве показывается число походов вместо общего числа товаров, в истории товара — число закрытых списков. Суммы и единицы/уникальные товары остаются в статистике; выбор позиций для повторной покупки и текущий прогресс сохранены. Добавлены тесты. Сборка и UI требуют подтверждения.


## 27.11.2026 — системные уведомления о новых версиях при входе

Проверка GitHub Releases только при переходе MainActivity в foreground (интервал защиты от повторных запросов 60 секунд; при явном включении уведомлений/разрешении проверка принудительная), coroutine отменяется при onStop, периодических задач/WorkManager/Firebase нет. Отдельный NotificationChannel, POST_NOTIFICATIONS на Android 13+, переключатель в AppUpdateSheet, уведомление один раз на новый versionCode выбранного канала. Нажатие открывает центральный диалог обновлений из запущенного и холодного приложения; загрузка и системная установка требуют явного действия. ## 27.11.2026 — временный кэш APK и восстановление оптимизации

Beta и Stable снова используют AGP optimization.enable=true, R8, ресурсную оптимизацию и стандартный release lint. Кэш Gradle, подпись, версионность и публикация сохранены. APK обновления хранится в cacheDir/updates с ключом версия+SHA-256; при повторном открытии валидируется и отображается «Установить» без повторной загрузки. После установки удаляется на следующем входе, при обнаружении более новой сборки прежние APK удаляются сразу. Неудачные загрузки удаляются; старый случайно названный APK переиспользуется только при полной проверке. Подпись/package/version/hash повторно проверяются перед установкой. Проверка кэша при входе не зависит от разрешения уведомлений; фоновые задачи не добавлены. При просмотре более старого канала более свежий ожидающий файл сохраняется до загрузки другого APK. Тесты политики добавлены, сборка и проверка на телефоне необходимы.
