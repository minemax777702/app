# Правила работы над проектом

- Перед работой по ТЗ прочитать `TZ_SHOPPING_APP_CODEX.md`, `CODEX_PROGRESS.md`, `CODEX_HANDOFF.md`, проверить состояние Git и фактический код.
- Выполнять только текущий этап в порядке 01–10; обновлять журнал и передачу после существенных изменений и перед завершением сеанса.
- Сборку и ограничения проверки выполнять с учётом `CLAUDE.md`; интерфейс и комментарии — на русском.

## UI/UX

- При анализе и изменении Android-интерфейса изучать `.agents/skills/mobile-android-design/SKILL.md`, `.agents/skills/mobile-ui-ux-designer/SKILL.md` и `.agents/skills/ui-android/SKILL.md`, применяя рекомендации с учётом задачи и правил пользователя.
- `ui-android` ориентирован на API 34+, тогда как проект поддерживает API 29+. Не повышать minSdk и не менять тему, зависимости или дизайн-систему только ради требований скилла. Для аудита применять его как чеклист без генерации кода и без этапа утверждения дизайна.
