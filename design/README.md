# Автоматический FIG

Один раз загрузить исходный редактируемый экспорт в `design/source.fig` в ветку beta. Внимание: репозиторий публичный. Не загружать приватный дизайн без разрешения. Не использовать сгенерированный FIG как источник, иначе будут дублироваться страницы.

В job ui-handoff после полного успешного захвата и до удаления неизменённых PNG создаётся артефакт shopping-list-fig: Shopping-list-latest.fig и JSON проверки.

Генератор сохраняет исходные узлы и блобы без изменений, добавляет две страницы с PNG в исходных физических пикселях и сверяет SHA-256 каждого снимка. Это точные растровые эталоны, не автоматическая реконструкция редактируемых Compose-слоёв. Импорт в Figma отдельно не проверяется; внутренний формат FIG не является стабильным публичным API. При несовместимой схеме или неполном захвате экспорт завершается ошибкой. Если source.fig отсутствует, шаг сообщает предупреждение, а остальные артефакты остаются доступны.

Локально: python3 scripts/update-fig.py --source design/source.fig --handoff ui-handoff --output design-output/Shopping-list-latest.fig

Требования: Python >=3.9 и libzstd.so.1. Ручной запуск FRESH CUT APK из beta или коммит с маркером [ui]. Для изменения существующих редактируемых фреймов необходим отдельный экспорт структуры Compose и сравнение рендеринга.
