Покупка, отмена, удаление и свайп вправо сохраняют прежние callbacks. Реальные жесты, конфликт с дочерними контролами и скорость кадров требуют прогона.

AppModalSheet: явное закрытие через LocalSheetClose и SearchSheetDragHandle выполняет sheetState.hide() до удаления композиции; защитные флаги closing/delivered предотвращают повторную доставку. Нативные Back/scrim/swipe используют Material, без повторного hide при Hidden. Required состояние учитывается актуальным confirmValueChange; программное закрытие после сохранения в отдельных формах по-прежнему управляется вызывающим экраном. Не менять механизм открытия/закрытия обязательного onboarding без отдельного теста.

Список покупок: один viewport вместо Crossfade двух веток, читавших текущие rows; убран потенциальный дублирующий layout при последней покупке. Header плавно меняет высоту через animateContentSize; прогресс рисуется без анимированного измерения ширины дочернего Box, процент соответствует фактическому прогрессу. Архив: общий контейнер animateContentSize сохраняется при переключении compact/expanded, а не создаётся только в раскрытой ветке. Навигация и уведомления остаются на стабильных якорях; дополнительные переходы между экранами не добавлены во избежание дублирования обработчиков Back и состояния.

Motion: сохранены 160/300/500 мс для быстрых/основных/прогресса, нативные timings Material для шторок, системные масштабы анимации. Foundations Pixso обновлён строкой Motion / timings (34:7883); статические канонические экраны не изменялись. scripts/capture-adaptive-ui.py: добавлены короткий свайп и намеренный левый свайп по созданному fixture-товару; после сохранения закрывается родительская шторка поиска. Unit-тест и сценарий добавлены, но не подтверждены завершённым CI. Не заявлять отсутствие jank/измеренные FPS без трассировки кадров на Android. ## Цикл 12 — загрузка, ошибки и восстановление

LentaCatalog: отсутствие массива items теперь является ошибкой ответа, а не пустым результатом. Для JSON/SSE добавлена проверка общего времени чтения (45 секунд с начала запроса) в дополнение к connect/read timeouts; бесконечные heartbeat не обходят проверку. Блокирующий сетевой read может завершиться позже общего дедлайна в пределах своего тайм-аута, это не гарантированный hard timeout.

LentaSearchController: отдельные pending/paused и идентификаторы текущего запроса/адреса; отмена поиска до/во время запроса, сохранение результатов и курсора, повтор ошибочной страницы. Для страницы coroutine timeout 45 с, для полного поиска — пауза после 30 страниц за один запуск с продолжением с курсора, без общего лимита страниц. Старый ответ не применяется после отмены. Пустое состояние только после успешного завершения; ошибки не объявляются отсутствием товаров. Добавлены 3 теста контроллера (отмена debounce, повтор страницы после ошибки, отмена активного запроса) и тест дедлайна SSE.

LentaUi: единое сообщение ошибки с действием Повторить вместо дублирования баннером; указание адреса, загрузка с подписью, остановка обычного/полного поиска, неполный результат с продолжением. Устаревший запрос не отображается; полная сортировка не выдаёт текущую страницу за окончательный рейтинг. Ранее найденные результаты доступны после остановки/сбоя, при активной полной сортировке прежняя политика скрытия предварительного рейтинга сохранена. Названия онлайн-товаров больше не ограничены двумя строками. ProductsScreen различает первичную загрузку локального каталога и пустой результат. FreshCutStatusCard — общий блок сообщения/действия.

SupabasePanel: отображение загрузки профиля, существующего статуса синхронизации и повторного запроса; отключённый доступ отдельно, без обещания восстановления соединением. Изменена только UI-презентация существующих состояний; схема, RLS, облачная логика и реальные данные не затрагивались.

AppUpdateSheet: отмена загрузки с сохранением возможности скачать повторно, при проверке целостности отмена скрыта; статус ошибки не маскируется наличием новой версии, отдельное действие Повторить проверку. Проверка релиза/истории имеет coroutine timeout 60 с (не hard timeout для блокирующего транспорта). История отменяется при смене канала; generation исключает применение устаревшего ответа при A→B→A. Проверки подписи/хеша, удаление временного файла и логика установки сохранены.

## Цикл 13 — пользовательские сценарии и навигация

- Покупки: сохранение LazyListState выше условного экрана уведомлений и вкладок; возврат из уведомлений не пересоздаёт позицию списка. Сканирование, отметка покупки, количество и завершение списка остаются прежними.
- Поиск: настройка адреса Ленты открывается поверх текущего добавления товара, поиска из каталога или выбора товара по сканированному штрихкоду. Не требуется закрыть поиск, перейти в профиль, открыть настройки и повторить ввод. Запрос и локальные состояния сохраняются, после смены адреса контроллер перезапускает поиск. Профиль по-прежнему позволяет изменить адрес отдельно.
- Каталог: «Найти в Ленте» — постоянное нижнее действие после загрузки, а не пункт overflow; при отсутствии локальных результатов также доступно «Создать свой товар». Дублирующий пункт создания скрыт в меню пустого состояния. Состояние прокрутки сохраняется через rememberLazyListState/SaveableStateProvider; новый запрос сбрасывает позицию.
- Магазин: «Добавить товар» перемещено из верхней панели в нижнюю закреплённую область; список магазинов и список товаров имеют отдельные состояния прокрутки, поиск/пагинация сохраняются при возврате и сбрасываются при новом запросе. Создание своего товара из picker подставляет название или цифровой штрихкод; отмена возвращает в picker с прежним запросом. Во время сохранения связи шторка обязательна, не закрывается случайным жестом. Явное закрытие формы цены сохраняет прежнее поведение; «Выбрать другой товар» возвращает к выбору. Правила цен, связь с магазином и удаление не менялись.
- Архив: возврат из информации о товаре в архивную детализацию, а затем к прежнему списку; состояние прокрутки сохраняется. Убран двойной нижний системный inset. Статистика, открытая из архива, возвращается в архив по Back; прямой переход через навигацию сохраняет прежнее поведение.
- Pixso: catalog (3:6804), catalog-populated (9:2802), Store detail master (28:2907/28:2954) и его связанные экземпляры обновлены; убраны две устаревшие иконки сортировки. Проверены четыре экспорта и геометрия шести узлов/экранов; обнаружено и исправлено устаревшее отображение текста в экземпляре кнопки. Основные канонические ключи не менялись.
- scripts/capture-adaptive-ui.py: добавлен audit_navigation — прямой поиск, вложенная настройка адреса (если адрес не задан), нижнее действие магазина, предзаполнение названия, отмена с возвратом. Только fixture; не изменяет реальный адрес и реальные магазины. Реальные действия, системный Back, сохранение скролла на Android и измерение удобства одной рукой ещё не подтверждены.
