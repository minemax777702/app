## Откат

Приостановить CI синхронизации Pixso и другие активные задачи, сохранить незакоммиченные изменения, проверить историю. Сначала создать резервную ветку от текущего beta для возможности отмены отката.

```bash
git fetch origin
git switch beta
git pull --ff-only origin beta
git status --short
git branch backup/ui-ux-before-restore
git push origin backup/ui-ux-before-restore
git restore --source=b37c8481a422343ba685e419e0a0fac1c233f46e --staged --worktree :/
git diff --cached --stat
git commit -m "restore: UI UX checkpoint 2026-11-28"
git push origin beta
```

Запускать restore только из чистой рабочей копии в корне репозитория; если резервная ветка уже существует, выбрать новое имя. Проверить diff до commit, не использовать force push. В Pixso сохранить текущую версию отдельно, затем открыть историю и восстановить именованную версию (после того, как она действительно создана). Проверить оба проекта и только потом снова включить CI. Не принимать baseline автоматически: на исходной точке он ещё ожидал проверки. Восстановление исходников не откатывает Supabase, установленные APK или опубликованные релизы. Если требуется APK, отдельно запросить новую beta-сборку с восстановленным кодом.
