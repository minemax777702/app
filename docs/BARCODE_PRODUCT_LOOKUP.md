# Поиск товара по штрихкоду

## Источники
- Open Food Facts: GET /api/v2/product/{code}.json — название, бренд, изображение.
- UPCitemdb: GET /prod/trial/lookup?upc={code} — название и изображения. Бесплатный тариф ограничен по числу запросов.
- Olegon: https://barcodes.olegon.ru/r.php?c={code} — дополнительный источник; доступ может требовать регистрации и ключа.
- DiSAI: https://ru.disai.org/barcode/ean-13/{code} — попытка извлечь название из публичных метаданных HTML-страницы; официальный API не подтверждён, стабильность не гарантируется. Отдельная кнопка открывает страницу в браузере.

## Поведение
1. Через 650 мс после ввода корректного штрихкода начинается необязательный поиск по включённым источникам (GS1 не используется). Сохранение товара от него не зависит.
2. Каждый API обрабатывается отдельно. 404, 429, таймаут, HTML вместо ответа и пустой ответ не должны нарушать форму.
3. Результаты очищаются от пустых / некорректных названий, дедуплицируются и ранжируются. Можно выбрать любое название либо написать своё.
4. Название автоматически заполняется, только если поле пусто и пользователь ещё не менял его сам.
5. Интернет-превью загружается в фоне после создания товара. Своё фото можно назначить через системный выбор изображения.
6. Фото хранится локально, не входит в QR-синхронизацию. Лимит изображения 4 МБ, скачивание только по HTTPS с разрешённых хостов.

## Проверка
- Успешный поиск и выбор названия.
- Работа без интернета.
- Несколько названий от разных провайдеров.
- Повторный поиск и обработка ограничений по частоте.
- Ручное имя не меняется автоматически.
- Собственное фото и обновление интернет-превью.
- Локальная сборка: ./gradlew :app:testDebugUnitTest :app:assembleDebug
