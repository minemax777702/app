# Поиск товара по штрихкоду

Внешние источники Open Food Facts, UPCitemdb, Olegon и DiSAI удалены. Штрихкоды сканируются камерой или вводятся вручную, сопоставляются с локальной базой (включая алиасы каталога Ленты). Для неизвестного кода можно создать товар вручную. Существующие фото сохраняются; новое фото выбирается из галереи. Каталог Ленты и его поиск по названию продолжают работать.
