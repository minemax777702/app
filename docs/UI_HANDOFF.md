## Автоматическая выгрузка

- [FRESH CUT APK](https://github.com/minemax777702/app/actions/workflows/figma-redesign-apk.yml), job `ui-handoff`, артефакт `fresh-cut-ui-handoff`.
- [FRESH CUT UI check](https://github.com/minemax777702/app/actions/workflows/figma-ui-check.yml) — отдельная проверка сборки и тестов, не источник скриншотов.
- [Последний подтверждённый запуск на момент привязки](https://github.com/minemax777702/app/actions/runs/46113599849), коммит `84cc87ff497cff303a655d1d9265e996e55cb72a`, [артефакт](https://github.com/minemax777702/app/actions/runs/46113599849/artifacts/15251127844). Это контрольная точка, не постоянная ссылка на последнюю версию.

Для каждого обновления выбирать самый свежий завершённый запуск ветки `beta` с успешным `ui-handoff` и неистёкшим артефактом. Запуски без сборки и пропущенные jobs не подходят.

## Работа с макетом

1. Получить ZIP `fresh-cut-ui-handoff` из выбранного запуска. Например, `gh run list -R minemax777702/app -w figma-redesign-apk.yml -b beta --limit 20`, затем `gh run download RUN_ID -R minemax777702/app -n fresh-cut-ui-handoff -D ui-handoff`.
2. Проверить `manifest.json`, `coverage_complete`, статусы экранов, `commit.txt`, `changed-files.txt` и `CHANGES.md`/`changes.json` при наличии. Успешный job сам по себе не гарантирует полное покрытие.
3. В режиме `full` использовать доступные PNG и XML обеих тем. В режиме `delta` обновлять только новые и изменённые экраны; неизменённые брать из ранее сохранённого полного набора/цепочки дельт. Не удалять фреймы при статусе `not_captured_in_current_run`. Если базовый набор недоступен, требуется полный захват.
4. Сопоставлять экраны с `REDESIGN.md` и исходным FIG; новые состояния добавлять по фактическим скриншотам, а не по предположениям. XML использовать для проверки видимого текста и структуры. Сохранять светлую и тёмную темы.
5. После обновления макета сохранять новый экспорт отдельно с идентификатором коммита приложения. Артефакты Actions хранятся 30 дней; полные наборы следует сохранять до истечения срока.

CI создаёт снимки отдельной сборки `uiCapture` с изолированными тестовыми данными. Это автоматическая передача фактического UI для обновления макета, а не автоматическая запись в Figma и не доказательство пиксельного совпадения с публичным APK.
