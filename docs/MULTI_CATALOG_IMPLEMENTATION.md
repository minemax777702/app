# Несколько каталогов, магазины и история фактических цен

**Ветка:** `feat/multi-catalog-stores-prices`, база `ui/polish-barcode-card`.
**Статус:** первый вертикальный срез, нуждается в локальной сборке/проверке миграции и дальнейших UI-правках.

## Принятая модель

- `lenta_products`: каталог Ленты без удаления/перезаписи.
- `custom_products`: каталог вручную созданных товаров с UUID и необязательным EAN/UPC.
- `stores`: справочник магазинов с UUID, создаётся при первой покупке с указанным названием.
- `items.customProductId`: UUID из своего каталога; старые `productId` и `nameKey=lenta:<id>` сохраняются.
- `PurchaseEvent`: расширен **добавлением полей в конец** двоичного формата (`customProductId`, `storeId`), обратное чтение старых записей сохранено.
- `Snapshot`: добавлены customProducts и stores, SyncCodec v9, объединение по UUID/updatedAt с приоритетом удаления при равной метке.
- Все цены — в **копейках**, nullable. Неизвестные значения не включаются в денежную статистику.
